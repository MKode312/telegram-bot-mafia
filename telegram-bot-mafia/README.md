# Telegram-бот «Мафия»

Бот для игры в мафию в групповом чате Telegram. Роли приходят в личные сообщения, ночные действия и голосование — кнопками в ЛС, объявления фаз — в группе.

Состояние партий хранится в памяти процесса: после перезапуска активные игры пропадают. Одновременно должен работать один экземпляр бота.

## Как играть

1. Добавьте бота в группу и выдайте право удалять сообщения (чтобы убирать команды из чата).
2. Каждый игрок один раз пишет боту в ЛС `/start` — иначе роль и кнопки не придут.
3. В группе: `/create` → кнопка «Присоединиться» → `/startgame` (создатель).
4. Ночь → обсуждение → голосование. Побеждает мафия, если живых мафиози не меньше, чем мирных; мирные — если мафии не осталось.

### Роли

| Роль | Команда | Ночью |
| --- | --- | --- |
| Мафия | мафия | выбирает жертву |
| Доктор | мирные | лечит игрока (не одного и того же две ночи подряд; себя — один раз за игру) |
| Детектив | мирные | проверяет роль или стреляет |
| Красотка | мирные | даёт алиби: днём за этого игрока нельзя голосовать |
| Мирный житель | мирные | без ночного действия |

Число мафии, доктора, детектива и красотки задаётся в YAML и зависит от размера лобби.

### Команды

| Команда | Где | Кто |
| --- | --- | --- |
| `/start` | ЛС (в группе только удаляется; приветствие уходит в ЛС, если чат уже открыт) | любой |
| `/help` | группа / ЛС | любой |
| `/create` | группа | любой |
| `/leave` | группа | игрок в лобби |
| `/game` | группа | любой |
| `/startgame` | группа | создатель |
| `/cancel` | группа | создатель, до старта |

## Локальный запуск

Нужны Go 1.25+ и токен бота от [@BotFather](https://t.me/BotFather).

```bash
cp .env.example .env
# пропишите BOT_TOKEN и CONFIG_PATH=./config/local.yaml
go run ./cmd
```

Либо:

```bash
export BOT_TOKEN=...
export CONFIG_PATH=./config/local.yaml
go run ./cmd
```

Тесты: `go test ./...`

## Конфиг

- `config/local.yaml` — локальная разработка (`env: local`, цветные логи).
- `config/prod.yaml` — сервер (`env: prod`, JSON-логи).

Путь к файлу: флаг `-config` или переменная `CONFIG_PATH`. Токен только из `BOT_TOKEN` (файл `.env` подхватывается, если лежит в рабочей директории).

В YAML задаются лимиты игроков, число мафии по размеру лобби, пороги спецролей (`min_players` / `count`) и таймеры фаз (`lobby`, `night`, `discussion`, `voting`).
